# 財報解讀與紅旗訊號

> 重點不在三大報表是什麼（模型熟知），而在**如何識別獲利品質與財報地雷**。

## 三大報表速覽

| 報表           | 看什麼           | 關鍵指標                       |
| -------------- | ---------------- | ------------------------------ |
| 損益表         | 賺多少、花多少   | 營收、毛利率、營益率、EPS      |
| 資產負債表     | 有多少、欠多少   | 流動比、負債比、存貨、應收帳款 |
| **現金流量表** | **真實現金進出** | **營業現金流、自由現金流**     |

> 📌 **現金流量表往往最重要**，因為「**獲利可以做帳，現金不會騙人**」。

## 看財報的順序（推薦）

1. **先看月營收趨勢**（每月 10 日前公布）
2. **再看季報損益表**：毛利率、營益率是否同步成長
3. **檢查現金流**：營業現金流是否與淨利同步
4. **評估資產負債**：負債比、存貨、應收是否合理
5. **與同業比較**
6. **看 4-8 季趨勢**，不要只看單季

## 月營收解讀（台股獨有）

### 重點指標

| 指標         | 計算                             |
| ------------ | -------------------------------- |
| 月營收 YoY   | (本月 − 去年同月) ÷ 去年同月     |
| 累計營收 YoY | (今年累計 − 去年累計) ÷ 去年累計 |

### 判讀

- **連續 3 個月以上 YoY 為正** → 進入正向循環
- **YoY 由正轉負** → 動能可能反轉
- **單月暴衝** → 可能是出貨集中，看 3 個月移動平均
- **基期效應**：去年低基期會放大今年成長率，看絕對金額

## ⚠️ 財報紅旗訊號（最關鍵）

模型最容易漏掉、但你必須要 KB 提醒的部分：

### 1. 應收帳款異常增加

- **應收帳款成長率 > 營收成長率 2 倍** → 警訊
- 代表「賣得出去但收不到錢」，可能是**衝營收給客戶寬鬆條件**
- ➤ 觀察「應收帳款週轉天數」是否拉長

### 2. 存貨膨脹

- **存貨成長率 > 營收成長率** → 警訊
- 可能是**需求下滑、產品滯銷或刻意囤貨**
- ➤ 觀察「存貨週轉天數」是否拉長

### 3. 營業現金流 < 淨利

- 淨利亮眼但營業現金流低 → **獲利品質差**
- 營業現金流 ÷ 淨利 健康值應 > 80%
- < 50% 為警戒
- ➤ 連續多季營業現金流為負，即使帳面獲利仍可能**資金斷鏈**

### 4. 業外損益佔比高

- 稅後淨利率 vs 營業利益率差異大 → 靠業外撐
- 業外（匯損、轉投資、出售資產）**不可持續**
- ➤ 看「**本業 EPS**」而非「**綜合 EPS**」

### 5. 頻繁更換會計師

- 公司主動更換簽證會計師 → 可能與會計師有財務認列分歧
- 公開資訊觀測站可查

### 6. 關係人交易比重高

- 與母子公司或大股東個人公司交易頻繁
- 可能有「**交易公允性**」問題（左口袋進右口袋）

### 7. 大額資產減損

- 商譽、存貨、設備減損 → 過去投資決策失敗
- 雖是一次性，但反映管理層判斷力

### 8. 毛利率持續下滑

- 連續 4 季以上毛利率下滑 → 競爭力流失或進入紅海
- 即使營收成長，獲利會被壓縮

## 獲利品質快速檢查表

| 檢查項                | 健康            | 警示                 |
| --------------------- | --------------- | -------------------- |
| 營業現金流 / 稅後淨利 | > 80%           | < 50%                |
| 應收帳款天數          | 穩定/下降       | 持續上升             |
| 存貨週轉天數          | 穩定/下降       | 持續上升             |
| 業外收入佔比          | < 20%           | > 50%                |
| 資本支出 / 折舊       | > 1（投資未來） | 長期 < 1（設備老化） |
| 毛利率趨勢            | 穩定/上升       | 連續下滑             |
| 流動比率              | > 1.5           | < 1                  |
| 負債比率              | < 50%（一般業） | > 70%                |

## 常見誤判

| 誤判                 | 真相                                       |
| -------------------- | ------------------------------------------ |
| 「EPS 創新高就買進」 | 要看是不是業外撐的、現金流是否同步         |
| 「營收成長就健康」   | 看毛利率是否同步，否則可能是低毛利衝量     |
| 「負債高就危險」     | 銀行業天然高負債，要看資本適足率           |
| 「現金多就好」       | 現金過多不投資反映管理層保守，可能錯失機會 |
