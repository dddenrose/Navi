# 關鍵財務比率解讀

> 工具 `analyze_fundamentals` 已自動回傳 PE/Forward PE/PB/PS/ROE/ROA/毛利率/營益率/淨利率/EPS/殖利率，本文聚焦**解讀眉角**而非公式。

## EPS（每股盈餘）

- EPS 越高 ≠ 越好，**成長趨勢**才是重點
- 連續 5 年以上 EPS 成長的公司，股價長期表現較佳
- 注意**基本 EPS** vs **稀釋 EPS**（後者考慮可轉債、員工選擇權）
- ⚠️ 單季 EPS 暴增可能來自業外（出售資產、匯兌），看本業才準

## PE（本益比）

### 種類差異

- **Trailing PE**：股價 ÷ 過去 12 月 EPS（已實現）
- **Forward PE**：股價 ÷ 未來 12 月預估 EPS（**比 Trailing 重要**）

### 解讀區間參考

| PE 區間 | 一般判讀               |
| ------- | ---------------------- |
| < 10    | 可能低估或基本面有問題 |
| 10-15   | 價值股合理區間         |
| 15-25   | 成長股合理區間         |
| 25-40   | 高成長預期，注意風險   |
| > 40    | 過度樂觀或特殊因素     |

⚠️ **不可絕對化**：高成長產業（半導體）PE 自然高，傳產股 PE 自然低，**跨產業比較沒意義**。

### 模型最容易出錯的眉角

- **景氣循環股 PE 是反指標**：谷底 EPS 趨近於零，PE 反而最高（看似貴實際是底部）
- **PEG 比率**：PE ÷ 盈餘成長率，PEG ≈ 1 為合理，< 1 為低估（更實用）

## PB（股價淨值比）

- **PB < 1**：股價低於帳面價值，可能低估也可能資產品質差
- **適用**：銀行、保險、營建、鋼鐵等**資產密集型**
- **不適用**：科技、品牌型公司（核心價值不在帳面）

## ROE（股東權益報酬率）— 巴菲特最愛

### 區間參考

| ROE    | 評價               |
| ------ | ------------------ |
| > 20%  | 優秀，可能有護城河 |
| 15-20% | 良好               |
| 10-15% | 一般               |
| < 10%  | 偏低               |

### ⚠️ 最關鍵眉角：杜邦拆解警示

$$
ROE = \text{淨利率} \times \text{資產周轉率} \times \text{權益乘數（槓桿）}
$$

**高 ROE 不一定是好公司！**

- 高 ROE + 高槓桿 = 用借錢撐獲利，**風險大**（如部分金融股）
- 高 ROE + 低淨利率 + 高週轉 = 薄利多銷型，需看護城河
- 高 ROE + 高淨利率 + 低槓桿 = **理想型**，真正的好公司

➤ 模型常只看 ROE 數字，忽略它的「來源」。看到 ROE 高一定要拆解。

### 偽 ROE 警訊

- ROE 突然提升但**淨利沒成長** → 可能是**大量買回庫藏股**減少股東權益所致，不是真實獲利能力增強

## 其他重要比率

### 毛利率

- 反映產品**定價權**
- 連續下滑 = 警訊（成本上升或降價競爭）
- 半導體：> 40% 為佳；零售：> 20% 即可
- **不可跨產業比**

### 營業利益率

- 反映**核心業務獲利能力**（排除業外）
- 與淨利率差異大 → 業外損益佔比高，獲利品質低

### 負債比率

- 一般公司 < 50% 為穩健
- **銀行業天然 90%+**，要看資本適足率（BIS）而非負債比

### 自由現金流（FCF）

$$
FCF = \text{營業現金流} - \text{資本支出}
$$

- 巴菲特稱「股東盈餘」(Owner Earnings)
- **正 FCF + 高 FCF/淨利比** = 真正能配息或擴張
- ⚠️ FCF 為負的公司即使 EPS 漂亮也要小心（現金可能斷鏈）

## 綜合解讀組合

| 組合                           | 意義                                 |
| ------------------------------ | ------------------------------------ |
| 高 ROE + 低 PE + 低槓桿        | **物美價廉**，最佳機會               |
| 高 ROE + 高槓桿                | 警戒，是借錢撐出來的                 |
| 高 ROE + 高 PE                 | 好公司但價格已反映，看成長性能否撐住 |
| 低 ROE + 低 PE                 | 便宜可能有原因，需深入研究           |
| EPS 成長 + 營收成長 + FCF 成長 | 三高，獲利品質高                     |
| EPS 成長 + 營收下滑            | 警訊！可能靠成本控制或業外撐         |
