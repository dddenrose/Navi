# 布林通道（Bollinger Bands）解讀重點

> 工具 `analyze_technicals` 已輸出布林上中下軌值，本文聚焦於解讀邏輯。

## 通道組成

- **中軌**：20 日移動平均（趨勢方向）
- **上軌**：中軌 + 2σ（壓力帶）
- **下軌**：中軌 − 2σ（支撐帶）
- **帶寬 (Bandwidth)**：(上軌 − 下軌) ÷ 中軌（衡量波動率）

## 核心觀念：通道是動態的，不是固定的

**布林最重要的不是「位置」，是「寬度的變化」。**

### 1. Squeeze（通道收縮）

- 帶寬縮窄到歷史低點 → **盤整蓄力**
- 「寧靜之後必有風暴」——大行情常從 Squeeze 開始
- ➤ 觀察方法：帶寬接近近 6 個月最窄

### 2. Expansion（通道擴張）

- 帶寬急速放大 → **趨勢行情啟動**
- 突破上軌 + 帶寬擴張 = 向上趨勢確認
- 跌破下軌 + 帶寬擴張 = 向下趨勢確認

### 3. Contraction（通道收斂）

- 帶寬從高點開始縮小 → **趨勢可能結束**
- 通常出現在一波行情走完之後

## 模型容易誤判的地方

### ❌ 「觸及上軌就要賣，觸及下軌就要買」

**錯！** 強趨勢中股價會沿著上軌（或下軌）持續行進，稱為「**走通道**」。

| 情境                | 正確判讀                           |
| ------------------- | ---------------------------------- |
| 帶寬擴張 + 沿上軌走 | 強多，續抱不動，跌破中軌再考慮出場 |
| 帶寬收縮 + 觸及上軌 | 區間震盪，可考慮做空回中軌         |
| 帶寬擴張 + 沿下軌走 | 強空，不要急著抄底                 |
| 帶寬收縮 + 觸及下軌 | 區間震盪，可考慮做多回中軌         |

➤ **是否能均值回歸取決於市場狀態**，必須先判斷趨勢還是盤整。

### ❌ 「布林假設股價符合常態分佈」

實際上股價有**厚尾**（fat tails），極端行情下通道會被「貫穿」。重大利空利多時不要過度依賴布林。

## 三種經典策略

### 策略一：Squeeze 突破策略

1. 等待帶寬縮窄到近 6 個月最低
2. 放量突破上軌 → 做多；放量跌破下軌 → 做空
3. 停損設在中軌

### 策略二：均值回歸（限盤整時）

1. 帶寬未明顯擴張，通道平行
2. 觸及上軌 + RSI > 70 → 減碼
3. 觸及下軌 + RSI < 30 → 加碼
4. 目標價：中軌

### 策略三：走通道（強趨勢時）

1. 帶寬擴張 + 股價沿上軌
2. 持有不動
3. 跌破中軌再出場

## %B 指標（位置量化）

$$
\%B = \frac{C - 下軌}{上軌 - 下軌}
$$

- %B = 1：在上軌
- %B = 0：在下軌
- %B = 0.5：在中軌

➤ 多檔個股比較相對位置時很方便。

## 搭配使用

- **布林 + RSI**：上軌 + RSI 超買 = 雙重警示
- **布林 + 量能**：突破時必須放量，縮量突破多為假突破
- **布林 + MACD**：Squeeze + MACD 金叉 = 高勝率突破
