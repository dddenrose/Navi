# MACD 解讀重點

> 工具 `analyze_technicals` 已計算 DIF、DEA(Signal)、Histogram 並標註金叉/死叉，本文聚焦解讀眉角。

## 三大訊號層次

### 1. 零軸位置（判斷大環境）

- **DIF 與 DEA 都在零軸上方** → 多頭環境
- **DIF 與 DEA 都在零軸下方** → 空頭環境
- **DIF 上穿零軸** → 由空轉多
- **DIF 下穿零軸** → 由多轉空

### 2. 金叉/死叉強弱差異（重要）

不是所有金叉都一樣強：

| 訊號 | 位置         | 強度                 |
| ---- | ------------ | -------------------- |
| 金叉 | **零軸之上** | 強多                 |
| 金叉 | 零軸之下     | 弱多（可能只是反彈） |
| 死叉 | **零軸之下** | 強空                 |
| 死叉 | 零軸之上     | 弱空（可能只是回檔） |

➤ 模型常忽略這個差異，把所有金叉視為同等買進訊號。

### 3. 柱狀圖（動能變化）

柱狀圖比金叉/死叉更早預警：

- 紅柱**縮短**：多頭動能減弱（股價可能還在漲）
- 綠柱**縮短**：空頭動能減弱（股價可能還在跌）
- ➤ 柱狀圖縮短常**領先價格反轉 3-5 日**

## 模型容易漏掉的眉角

### 1. 連續背離才可靠

- **頂背離**：股價創新高，DIF 或柱狀圖未創新高
- **底背離**：股價創新低，DIF 或柱狀圖未創新低
- 單次背離常被打臉，**連續 2 次以上**勝率才高

### 2. 盤整行情容易被洗

MACD 在窄幅盤整時，金叉/死叉頻繁出現假訊號：

- ➤ 應先判斷是否在趨勢行情（搭配 ADX 或均線排列）
- ➤ 盤整時改看 KD 或布林通道，不用 MACD

### 3. 滯後性

MACD 是基於均線的二次計算，**天生滯後**：

- 金叉出現時，股價往往已經漲一段
- 用於確認趨勢可，但不適合作為**唯一**進場訊號

## 參數選擇

- **預設 (12, 26, 9)**：適合中長線
- **短線 (8, 17, 9)**：訊號多但假訊號也多
- **長線 (19, 39, 9)**：更平滑，適合月線分析

## 搭配使用

- **MACD 金叉 + 量能放大**：訊號加強
- **MACD + 均線多頭排列**：強多訊號
- **MACD + RSI**：MACD 確認趨勢、RSI 過濾超買超賣

## 適用與不適用

✅ 趨勢確認、找動能轉折、過濾雜訊  
❌ 窄幅盤整（頻繁假訊號）、極短線（滯後性大）
