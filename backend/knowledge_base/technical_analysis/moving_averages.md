# 移動平均線（MA）解讀重點

> 工具 `analyze_technicals` 已計算 MA(5/10/20/60) 並判別多頭/空頭/糾結排列，本文聚焦解讀邏輯。

## 台股常用週期

| 均線      | 週期   | 別稱 | 意義                     |
| --------- | ------ | ---- | ------------------------ |
| 5MA       | 一週   | 週線 | 極短線方向               |
| **20MA**  | 一個月 | 月線 | **最常用，短中線分水嶺** |
| 60MA      | 一季   | 季線 | 中線趨勢                 |
| **240MA** | 一年   | 年線 | **牛熊分界線**           |

## 核心判讀

### 1. 排列狀態（你工具會判定）

- **多頭排列**：5MA > 20MA > 60MA > 240MA，全部向上 → 強多趨勢
- **空頭排列**：5MA < 20MA < 60MA < 240MA，全部向下 → 強空趨勢
- **均線糾結**：多條均線交纏 → **盤整，即將選擇方向**（最值得關注的狀態）

### 2. 黃金交叉/死亡交叉強弱差異

不是所有交叉都同等強度：

| 訊號       | 條件                              | 強度         |
| ---------- | --------------------------------- | ------------ |
| 強黃金交叉 | 短均上穿長均，**兩條都向上**      | 高勝率       |
| 弱黃金交叉 | 短均上穿長均，**長均仍走平/向下** | 可能只是反彈 |
| 強死亡交叉 | 短均下穿長均，**兩條都向下**      | 高勝率       |

➤ 模型常把所有交叉等同看待，要強調這個差異。

### 3. 葛蘭碧八大法則（核心 4 個買賣訊號）

**買進訊號**：

1. 均線從下降轉走平/上升，股價突破均線 → 買
2. 股價跌破上升均線後又站回 → 買
3. 股價在上升均線上方拉回但未跌破 → 加碼
4. 股價急跌遠離均線（大幅負乖離） → 短線搶反彈

**賣出訊號**：對應的鏡像。

## 模型容易漏掉的眉角

### 1. 乖離率回歸

$$
\text{乖離率} = \frac{C - MA}{MA} \times 100\%
$$

- 乖離率過大（如 ±10% 以上對 20MA） → **有回歸均線傾向**
- 台股 20MA 乖離率 > 10% 視為超漲，< -10% 視為超跌

### 2. 均線扣抵效應

均線受「即將被扣除的舊資料」影響：

- 即將扣除的是**低價** → 均線即使橫盤也會「自動上升」
- 即將扣除的是**高價** → 均線即使橫盤也會「自動下降」
- ➤ 這就是為何「明明股價沒漲，季線卻持續上揚」的原因

### 3. SMA vs EMA 取捨

| 特性 | SMA        | EMA        |
| ---- | ---------- | ---------- |
| 計算 | 等權重     | 近期權重高 |
| 訊號 | 較少假訊號 | 反應靈敏   |
| 適用 | 中長線     | 短線       |

## 適用與不適用

✅ 趨勢市場、判斷大方向、設動態停損  
❌ 盤整市場（頻繁假交叉）、剛上市/剛除權後（資料失真）

## 搭配使用

- **MA + 量能**：突破均線需放量確認
- **MA + RSI**：MA 定方向，RSI 找進出場時機
- **MA + 支撐壓力**：均線在多頭時是動態支撐，空頭時是動態壓力
