# KD（隨機指標）解讀重點

> 工具 `analyze_technicals` 已計算慢速 KD(9,3,3)，本文聚焦解讀。台股慣用「**慢速 KD**」（平滑係數 1/3）。

## 區間意義

| K 值區間    | 意義   |
| ----------- | ------ |
| K > 80      | 超買區 |
| 20 < K < 80 | 中性區 |
| K < 20      | 超賣區 |

## 主要訊號

### 1. 金叉/死叉（最常用）

- **金叉**：K 線由下穿越 D 線 → 買進
  - **超賣區金叉（K<20）**：強多，勝率高
  - **中性區金叉**：弱多
- **死叉**：K 線由上跌破 D 線 → 賣出
  - **超買區死叉（K>80）**：強空，勝率高
  - **中性區死叉**：弱空

### 2. 背離（反轉預警）

- **頂背離**：股價創新高，K 值未創新高 → 動能衰退
- **底背離**：股價創新低，K 值未創新低 → 動能衰退
- 連續 2 次以上背離才可靠

## 模型最容易誤判的：「鈍化」

**KD 比 RSI 更容易鈍化。**

### 高檔鈍化

- K 值持續在 80 以上 → **強多頭趨勢，不要急著放空**
- 等 K 值明確跌破 80 + 出現死叉再考慮減碼

### 低檔鈍化

- K 值持續在 20 以下 → **強空頭趨勢，不要急著抄底**
- 等 K 值明確站上 20 + 出現金叉再考慮進場

➤ 這是新手最常踩的雷：在強趨勢中「看 KD 超買就空、超賣就買」，被連續打臉。

## KD vs RSI 比較

| 比較     | KD         | RSI            |
| -------- | ---------- | -------------- |
| 靈敏度   | 高         | 中             |
| 適用     | 短線、波段 | 中線           |
| 鈍化     | **容易**   | 較不容易       |
| 主要訊號 | 金叉/死叉  | 超買/超賣/背離 |

## 進階應用

### 多週期分析（推薦）

- **週 KD 定方向**：判斷中期趨勢
- **日 KD 找時機**：搭配週 KD 同向時進場
- 例：週 KD 金叉 + 日 KD 也金叉 → 高勝率買點

### 與均線搭配

- KD 金叉 + 站上 20MA = 雙重確認進場
- KD 死叉 + 跌破 20MA = 雙重確認出場

## 適用與不適用

✅ 盤整波段、短線進出、找鈍化結束時機  
❌ 強單邊趨勢（鈍化期）、長線投資（雜訊太多）
