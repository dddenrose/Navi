# 支撐與壓力（Support & Resistance）

> 工具 `analyze_technicals` 已計算支撐位、壓力位、費波那契回撤位、停損價。本文聚焦解讀邏輯。

## 核心觀念

> 支撐與壓力是**價格區間**而非精確一條線，實戰中應視為「**帶**」。

### 形成原因

- **套牢解套心理** → 套牢者反彈時想賣 → 形成壓力
- **獲利回補心理** → 賣出者股價回落想買回 → 形成支撐
- **整數關卡** → 50、100、500 等心理錨定
- **籌碼密集區** → 大量成交集中的價格帶

## 找出支撐壓力的六種方法

### 1. 前高前低（最基本）

- 前波低點 → 未來支撐
- 前波高點 → 未來壓力
- **被測試越多次未破**：強度越強
- **停留時間越長 + 大量成交**：強度越強

### 2. 整數關卡

- 50、100、200、500、1000 在權值股最明顯
- 大盤萬點、兩萬點

### 3. 均線（動態支撐壓力）

- **多頭時**（價在均線上方）：均線為支撐
- **空頭時**（價在均線下方）：均線為壓力
- 多條均線匯聚 → 支撐/壓力大幅加強
- 重要程度：240MA（年線）> 60MA（季線）> 20MA（月線）

### 4. 趨勢線

- **上升趨勢線**：連接波段低點，作支撐
- **下降趨勢線**：連接波段高點，作壓力
- 至少需被 **3 次以上**測試才較可靠
- 太陡（> 60 度）的趨勢線容易被跌破

### 5. 費波那契回撤

關鍵回撤比率：

| 比率      | 意義                 |
| --------- | -------------------- |
| 38.2%     | 強勢趨勢的第一道支撐 |
| **50.0%** | 心理重要分界         |
| **61.8%** | 黃金比率，最重要     |
| 78.6%     | 趨勢瀕臨反轉         |

計算：上漲段 A→B 的回撤位 = B − (B − A) × 比率

### 6. 跳空缺口

- **突破缺口**：強支撐/壓力
- **逃逸缺口**：中等
- **竭盡缺口**：弱，常被回補
- ➤ 「缺口必補」**不是定律**，強勢突破缺口未必補

## 最重要原則：支撐壓力互換

> **支撐被跌破 → 變壓力**  
> **壓力被突破 → 變支撐**

### 判斷有效性

| 條件           | 說明               |
| -------------- | ------------------ |
| **收盤價確認** | 盤中短暫穿越不算   |
| 幅度 > 3%      | 超過 3% 較可靠     |
| 連續 2-3 日    | 站穩才有效         |
| 放量配合       | 縮量突破多為假突破 |

## 匯聚區（Confluence Zone）

當多個方法指向同一價位時，該區域可靠度大幅提升：

範例：150 元附近同時是

- 前波低點（148）
- 60MA（149）
- 費波那契 38.2%（151）
- 上升趨勢線（150）

→ 148-151 元為**強力支撐匯聚區**

➤ **至少 2-3 個方法重疊**才算有效匯聚區。

## 實戰應用

### 進場策略

| 策略       | 條件                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| 支撐買     | 股價回至支撐 + 出現止跌訊號（紅 K、KD 金叉、量縮）→ 停損設支撐下方 2-3% |
| 突破壓力買 | 帶量突破 + 收盤站穩 + 不跌回 → 停損設原壓力位（轉為新支撐）             |

### 設定目標與停損

風險報酬比 = (進場到目標壓力) ÷ (進場到停損支撐) ≥ **2:1** 才值得進場

範例：進 100、停損 95、目標 115 → 風報比 = 15 / 5 = 3:1 ✅

## 限制

- 支撐壓力是區間，不要期望精確到某個價
- 重大消息可直接穿越所有支撐壓力
- 主觀性高（不同人畫的趨勢線不同）
- 不適用於低成交量個股
