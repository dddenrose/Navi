# RSI（相對強弱指標）解讀重點

> 工具 `analyze_technicals` 已自動計算 RSI(14) 並標註超買/超賣狀態，本文聚焦於**解讀眉角**，公式不在此重述。

## 區間意義（標準 14 日）

- **RSI > 70**：短期超買，回檔風險升高（**但非賣出訊號**）
- **30 < RSI < 70**：中性區間，趨勢延續
- **RSI < 30**：短期超賣，可能反彈（**但非買進訊號**）
- **RSI = 50**：多空動能平衡分水嶺

## 模型容易漏掉的關鍵眉角

### 1. 強趨勢中 RSI 會「鈍化」

- 強多頭時：RSI 可長期維持在 70 以上 → **此時看到 70 就放空是大忌**
- 強空頭時：RSI 可長期維持在 30 以下 → **此時看到 30 就抄底常被套**
- ➤ 鈍化期間，等待 RSI 從超買/超賣明確回到中性區並出現反轉訊號才動作

### 2. 背離（最有價值的訊號）

- **頂背離**：股價創新高，RSI 未創新高 → 上漲動能衰退
- **底背離**：股價創新低，RSI 未創新低 → 下跌動能衰退
- ➤ **單次背離不可靠**，連續 2-3 次背離才有較高勝率
- ➤ 背離只是「動能警訊」，不代表立刻反轉，需配合反轉 K 線確認

### 3. 失敗擺盪（Failure Swing）

比背離更可靠的反轉確認訊號：

- **看多失敗擺盪**：RSI 跌破 30 → 反彈 → 再跌但未創新低 → 突破前次反彈高 → 進場
- **看空失敗擺盪**：RSI 突破 70 → 回落 → 再升但未創新高 → 跌破前次回落低 → 出場

### 4. 50 軸線交叉

中線交叉常被忽略但很有用：

- RSI 由下穿越 50 → 動能轉多
- RSI 由上跌破 50 → 動能轉空
- 比 70/30 訊號頻繁，適合波段操作

## 與其他指標搭配

- **RSI + 布林通道**：RSI 超買 + 觸及上軌 = 雙重警示
- **RSI + 量能**：背離 + 量能萎縮 = 高勝率反轉訊號
- **RSI + MA**：RSI 中性 + 多頭排列 = 抗回檔強

## 適用與不適用

✅ 盤整市場、中線波段、找背離  
❌ 強單邊行情（鈍化失準）、極小型股（噪音大）
