# 台股交易規則與成本

## 交易時間

| 時段     | 時間          | 說明                            |

| 盤前撮合 | 08:30 - 09:00 | 集合競價，9:00 開盤             |
| 一般盤   | 09:00 - 13:30 | 連續競價（自 2020 年 3 月起）   |
| 收盤撮合 | 13:25 - 13:30 | 集合競價決定收盤價              |
| 盤後零股 | 13:40 - 14:30 | 盤後零股交易                    |

> ⚠️ 美股是 T+2 結算，**台股也是 T+2 交割**，但**T+0 即可賣出**（先買後賣的當沖）。

## 漲跌停限制

- **一般股票**：±10%
- **興櫃股票**：無漲跌停限制
- **新上市櫃首 5 日**：無漲跌停限制
- **ETN/ETF**：通常 ±10%，**槓桿型 ±20%、反向型 ±10%**
- **權證**：無漲跌停（依標的股價變動計算）

## 交易成本

### 1. 手續費

- 法定上限 0.1425%（買賣各收一次）
- 多數券商提供電子下單折扣 28-65 折，實務約 0.05% ~ 0.1425%
- 最低收費 1 元或 20 元（依券商規定）

### 2. 證券交易稅（賣出時收取）

| 標的                  | 稅率                         |
| --------------------- | ---------------------------- |
| **一般股票**          | 0.3%                         |
| **ETF**（含槓反 ETF） | **0.1%**                     |
| **當日沖銷**          | 減半至 **0.15%**（一般股票） |
| **公司債、政府債**    | 免稅                         |

### 3. 完整成本範例

買進 100 萬、賣出 100 萬一般股票：

| 項目                  | 金額                      |
| --------------------- | ------------------------- |
| 買進手續費（0.1425%） | 1,425 元                  |
| 賣出手續費（0.1425%） | 1,425 元                  |
| 證交稅（0.3%）        | 3,000 元                  |
| **單趟總成本**        | **5,850 元（約 0.585%）** |

> 📌 **損益兩平門檻**：股價需上漲 **約 0.6%** 才能打平交易成本（未折扣下單），有電子下單折扣可降至 0.4% 左右。

## 股利所得稅

### 兩種申報方式（擇優）

#### 方式一：合併申報（適合低稅率族群）

- 股利併入綜合所得稅一起申報
- **可抵減稅額 = 股利 × 8.5%**，每戶上限 8 萬元
- 適合所得稅率 5% / 12% 者

#### 方式二：分開計稅（適合高稅率族群）

- 股利按 **28% 單一稅率**分開計算
- 不可抵減
- 適合所得稅率 30% / 40% 者

### 計算範例

某人股利所得 50 萬，綜合所得適用稅率 30%：

- 合併申報應納稅額：50 萬 × 30% − 50 萬 × 8.5% = 11.75 萬
- 分開計稅應納稅額：50 萬 × 28% = 14 萬
- → 此例選**合併申報**較划算（差 2.25 萬）

## 二代健保補充保費

### 適用條件（股利相關）

- **單筆股利 ≥ 20,000 元**：扣 **2.11%** 補充保費
- 上限：單筆 1,000 萬元（最多扣 21.1 萬）

### 計算範例

某次配息 30,000 元 → 補充保費 = 30,000 × 2.11% = 633 元

> 📌 **節稅技巧**：若股利接近 2 萬元門檻，可考慮**分散持股或除息前賣出部分**，避開單筆 ≥ 2 萬的扣繳。

## 除權息相關

| 名詞         | 定義                                     |
| ------------ | ---------------------------------------- |
| 除權         | 配發股票股利（增加股數）                 |
| 除息         | 配發現金股利（股價扣除股息）             |
| 基準日       | 確認股東名冊日                           |
| 除權/息日    | 股價向下調整日（前一交易日後收盤後計算） |
| 最後過戶日   | 基準日前 5 個營業日（含當日）            |
| 停止過戶期間 | 基準日前 5 日 ~ 基準日                   |

### 填權息與棄權息

- **填權息**：除權息後股價漲回除權息前 → 真正享受到股利
- **棄權息**：除權息後股價持續低於除權息前 → 領了股利但股價沒回補
- **貼權息**：股價跌得比除息點更低，連本金都損失

### 棄權息的考量

若所得稅率高，領股利反而要繳更多稅，賣出避開除權息可能更划算：

$$
\text{臨界點} = \text{股利} \times (\text{邊際稅率} - 8.5\%)
$$

## 不同類股的特殊規則

### ETF

- 證交稅 0.1%（vs 一般股票 0.3%）
- 多數有「**折溢價**」，需檢查 NAV 與市價差
- 槓桿/反向 ETF **長期持有有耗損**（每日重設機制）

### 興櫃股票

- 無漲跌停
- 採議價交易，流動性差
- 散戶不建議參與

### 全額交割股

- 全額繳款才能買入（無法用融資）
- 通常是淨值低於 5 元、財報異常等問題股

### 處置股

- 連續異常波動會被列為處置（人工撮合、增加交割保證金）
- 短期投機熱錢標的，**散戶應避開**

## 常見錯誤

| 錯誤                       | 後果                         |
| -------------------------- | ---------------------------- |
| 忽略交易成本，頻繁交易     | 一年下來磨損可能超過 5-10%   |
| 未考慮稅務影響做除權息決策 | 高所得族群可能領股利反而吃虧 |
| 持有槓反 ETF 超過 1 個月   | 因每日重設機制造成嚴重耗損   |
| 在處置股盤中以市價買賣     | 可能因人工撮合大幅滑價       |
