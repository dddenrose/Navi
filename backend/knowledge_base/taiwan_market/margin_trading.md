# 融資融券與信用交易

## 定義

融資融券是台股的信用交易制度，散戶可向券商借錢（融資）做多，或借股票（融券）做空。融資融券餘額是**散戶情緒與壓力**最直接的指標。

> 📌 **核心觀念**：融資 ≈ 散戶看多力道；融券 ≈ 看空力道。**融資融券常是反指標**——散戶過度樂觀（融資爆量）或過度悲觀（融券爆量）時，往往是反轉點。

---

## 基本術語

| 術語             | 定義                                           |
| ---------------- | ---------------------------------------------- |
| 融資餘額         | 投資人向券商借錢買進尚未還款的張數             |
| 融券餘額         | 投資人借股票賣出尚未回補的張數                 |
| 融資使用率       | 融資餘額 ÷ 融資配額上限 × 100%                 |
| 券資比           | 融券餘額 ÷ 融資餘額 × 100%                     |
| 資券相抵（當沖） | 同一交易日先買後賣（或先賣後買）的現股當沖     |
| 強制回補         | 因除權息或股東會等原因，融券需在期限前強制買回 |

## 量價籌碼四象限

融資 vs 股價的搭配判讀：

| 型態         | 意義             | 判讀                                             |
| ------------ | ---------------- | ------------------------------------------------ |
| **價漲資增** | 散戶追高         | ⚠️ 短多但**過熱訊號**，特別是融資增幅 > 股價漲幅 |
| **價漲資減** | 散戶不信任的上漲 | ✅ **健康**，籌碼安定，續漲機率高                |
| **價跌資增** | 散戶逢低攤平     | ⚠️ 危險，套牢籌碼累積，反彈賣壓重                |
| **價跌資減** | 散戶停損認賠     | ✅ 籌碼出清，常出現在底部                        |

> 📌 最佳組合是**「價漲資減 + 法人買超」**——主力承接、散戶下車。

## 券資比解讀

$$
券資比 = \frac{融券餘額}{融資餘額} \times 100\%
$$

| 券資比區間 | 意義                                       |
| ---------- | ------------------------------------------ |
| < 10%      | 正常，無顯著看空力道                       |
| 10-30%     | 看空者增加，需留意是否有利空               |
| **> 30%**  | **軋空候選**，若有意外利多容易出現軋空行情 |
| > 50%      | 極端值，警戒主力誘空後拉抬                 |

### 軋空行情（Short Squeeze）

當券資比偏高、股價開始上漲時，融券者被迫回補（買回），形成「越漲越多人被迫買」的正回饋：

- **觸發條件**：高券資比 + 突然利多 + 法人買超
- **行情特徵**：連續跳空漲停、量能急放
- **歷史案例**：航運股 2021、AI 概念股 2023

---

## 強制回補規則

融券者在以下事件前必須強制回補（買回）：

| 事件     | 強制回補時點                                                       |
| -------- | ------------------------------------------------------------------ |
| 除權息   | 除權息基準日**前 6 個營業日**起停資停券，最後回補日為停券日前 1 日 |
| 股東會   | 股東會召開**前 60 個營業日**強制回補                               |
| 現金增資 | 認股基準日前停資停券                                               |

### 操作意涵

- **回補日前 5-10 日**：高券資比個股容易有「軋空行情」
- **每年 5-6 月（股東會旺季）**：是軋空高峰期
- **6-9 月（除權息旺季）**：除息前融券回補可能造成短期上漲

> ⚠️ 投資人若做多遇到強制回補軋空，常誤以為是基本面利多，需冷靜判斷。

---

## 融資使用率的警示意義

- **個股融資使用率 > 50%**：散戶集中下注，**反指標**
- **大盤融資餘額創波段新高 + 大盤未創新高**：⚠️ 高檔背離，行情可能轉弱
- **大盤融資餘額大幅縮減 + 大盤跌深**：✅ 散戶投降，可能接近底部

---

## 當沖（資券相抵）

- 反映**短線投機熱度**
- 當沖佔比 > 40% 的個股 = 主力遊資操控的熱門票
- 個股當沖率突然飆高 → 注意是否有炒作疑慮
- ➤ 不建議散戶做當沖：短期成功率低、手續費磨損大

---

## 常見誤判

| 誤判                   | 真相                                               |
| ---------------------- | -------------------------------------------------- |
| 「融資增加 = 看多」    | 融資增加常是**散戶看多**，散戶常是反指標           |
| 「融券高 = 一定軋空」  | 需配合資金流向；只有融券高但無催化劑，行情仍會走弱 |
| 「強制回補日一定大漲」 | 若大盤環境不佳，回補也撐不住                       |

---

## 實戰應用流程

1. **檢視融資使用率**：> 50% 的個股要特別小心，散戶過度集中
2. **觀察價量資三者關係**：「價漲資減」最健康，「價漲資增」要警戒
3. **檢查券資比**：> 30% + 即將強制回補 = 潛在軋空候選
4. **對照三大法人**：法人買 + 融資減 = 籌碼換手到強手，最佳訊號
5. **避開融資融券雙高的個股**：多空雙方都重壓，波動會非常大
