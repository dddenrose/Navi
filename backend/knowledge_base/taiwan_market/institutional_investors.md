# 三大法人籌碼解讀

## 定義

台股的「三大法人」指外資（含外資自營商）、投信、自營商三類機構投資人。每日盤後由證交所（TWSE）與櫃買中心（TPEx）公布買賣超數據，是台股最受關注的籌碼指標之一。

> 📌 **核心觀念**：法人不是萬能，但**散戶與法人對作的勝率長期偏低**。法人動向是趨勢的重要參考，但需區分「誰在買、買多久、為什麼買」。

---

## 三大法人特性比較

| 法人類型 | 資金性質                | 操作風格             | 持股週期   | 影響力                          |
| -------- | ----------------------- | -------------------- | ---------- | ------------------------------- |
| 外資     | 海外基金、主權基金、ETF | 中長線、權值股為主   | 數月～數年 | **最大**（佔台股市值 4 成以上） |
| 投信     | 國內共同基金            | 中短線、主題與題材股 | 數週～數月 | 中等（受基金績效壓力大）        |
| 自營商   | 券商自有資金            | 短線、避險為主       | 數日～數週 | 較小（部位受監管限制）          |

### 各自的「行為訊號」

- **外資連續買超**：通常代表中長線看好，特別是大型權值股（台積電、聯發科、鴻海）
- **投信連續買超**：常見於月底/季底「作帳行情」，或主題題材股（AI、軍工、生技）
- **自營商買超**：多為避險或客戶委託對沖，**參考價值最低**
- **三大法人同步買超**：強多訊號
- **三大法人同步賣超**：強空訊號，特別當外資也賣時更需警戒

## 解讀工具輸出

`get_institutional` 工具回傳資料對照（預設查詢近 5 日）：

| 欄位                    | 意義                         | 解讀                     |
| ----------------------- | ---------------------------- | ------------------------ |
| `foreign_buy/sell/net`  | 外資當日買進/賣出/淨額（張） | 淨額正 = 買超，負 = 賣超 |
| `trust_buy/sell/net`    | 投信當日數據                 | 同上                     |
| `dealer_buy/sell/net`   | 自營商當日數據               | 同上                     |
| `consecutive_buy_days`  | 連續買超天數                 | ≥ 5 日視為「連買」訊號   |
| `consecutive_sell_days` | 連續賣超天數                 | ≥ 5 日視為「連賣」警訊   |
| `cumulative_net`        | 期間累計淨額                 | 判斷整體方向強度         |

### 連買/連賣的解讀眉角

- **連買 3-5 日**：短線偏多，但需確認價格是否同步上漲
- **連買 10 日以上**：中線趨勢確立，回檔常為買點
- **連買但股價不漲**：警訊！可能是「換手出貨」或外資對作避險部位
- **連賣但股價不跌**：可能有大戶/主力承接，反而是底部訊號

## 進階指標

### 持股比率變化（更可靠）

單日買賣超容易被噪音干擾，**持股比率的變化**才是中長線真實方向：

- 外資持股比連續上升 → 真正的中長線看好
- 持股比下降但股價上漲 → **要非常小心**，可能是散戶接手的逃命波

### 投信季底作帳

每季最後一個月（3、6、9、12 月），投信會拉抬持股以美化基金淨值：

- **季底前 2 週**：投信主買股容易有作帳行情
- **季底結束後**：作帳結束的個股容易回檔
- ➤ 可從投信前 50 大持股中尋找候選

### 外資選擇權與期貨部位

外資現貨買賣超**不能單獨看**，要對照：

- **外資台指期未平倉**（TX）：多單增加 = 看多
- **外資選擇權 Put/Call Ratio**：Put 增多 = 避險或看空
- ➤ 若外資現貨買超但期貨大量空單，可能只是套利或避險，**不代表真看多**

## 常見誤判

| 誤判                          | 真相                                                      |
| ----------------------------- | --------------------------------------------------------- |
| 「外資連買 N 日，跟單就對了」 | 外資也會錯，2022 年台積電從 688 跌到 370 期間外資多次買超 |
| 「自營商買超 = 看多」         | 自營商常為避險或客戶單，方向意義最弱                      |
| 「投信買超等於股價上漲」      | 投信受贖回壓力影響大，可能買完隔日就被迫賣                |
| 「三大法人合計買超 = 多頭」   | 需拆開看，外資買、投信賣、互相抵銷的買超毫無意義          |

## 實戰應用流程

1. **先看外資方向**（最重要）
2. **對照投信**：兩者同向 = 訊號加強；反向 = 訊號弱
3. **看連續性**：連 3 日以上才有意義，單日數據雜訊大
4. **對照價格走勢**：量價籌碼三者一致才是高勝率訊號
5. **避開自營商主導的買賣超**：參考價值最低
6. **重大事件前後加倍小心**：Fed 會議、台灣大選、財報週前後法人常做大幅度調整
