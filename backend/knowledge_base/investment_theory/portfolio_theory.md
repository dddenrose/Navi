# 投資組合理論與績效指標

## 概述

投資組合理論（Modern Portfolio Theory, MPT）由 Harry Markowitz 於 1952 年提出，獲 1990 年諾貝爾經濟學獎。核心觀念：**透過資產組合最佳化，可在相同預期報酬下將風險降到最低**。

---

## 一、Markowitz 投資組合理論（MPT）

### 核心觀念

- 單一資產的風險（波動率）並不重要，**重要的是資產加入組合後對整體風險的貢獻**
- 透過**低相關性**的資產組合，可消除個別資產的特有風險（非系統性風險）
- 剩下的**系統性風險**（市場風險）無法透過分散消除

### 效率前緣（Efficient Frontier）

在所有可能的投資組合中，**相同風險下報酬最高、相同報酬下風險最低**的組合所構成的曲線。

| 概念                 | 意義                                   |
| -------------------- | -------------------------------------- |
| 效率前緣上的組合     | 最佳組合                               |
| 效率前緣下方的組合   | **應該避免**（同樣風險有更高報酬選擇） |
| 切線組合（市場組合） | 加入無風險資產後最佳的風險資產組合     |

### 實務啟示

- 不要看單一資產報酬，要看**它在組合中的貢獻**
- **相關性低**的資產才有分散效果（同類股之間相關性高，分散效果有限）
- 加入債券、黃金、現金等低相關資產可降低組合風險

## 二、相關係數與分散效果

$$
\rho_{A,B} = \frac{Cov(R_A, R_B)}{\sigma_A \sigma_B}
$$

| 相關係數  | 分散效果                   |
| --------- | -------------------------- |
| ρ = +1    | 完全正相關，**無分散效果** |
| 0 < ρ < 1 | 部分分散效果               |
| ρ = 0     | 不相關，**良好分散**       |
| ρ < 0     | 負相關，**最佳分散**       |

### 實例

| 組合            | 相關性                          |
| --------------- | ------------------------------- |
| 台積電 + 聯發科 | ρ ≈ 0.6-0.8（同產業，分散有限） |
| 台積電 + 統一超 | ρ ≈ 0.3-0.5（不同產業，較佳）   |
| 股票 + 美國公債 | ρ ≈ -0.2 ~ 0.2（很好的分散）    |
| 股票 + 黃金     | ρ ≈ -0.1 ~ 0.3（避險效果）      |

## 三、CAPM 與 Beta

### CAPM（資本資產定價模型）

$$
E(R_i) = R_f + \beta_i (E(R_m) - R_f)
$$

- $R_f$：無風險利率（如美國 10 年公債）
- $E(R_m)$：市場預期報酬
- $\beta_i$：個股對市場的敏感度

### Beta 解讀

| Beta      | 意義                                 |
| --------- | ------------------------------------ |
| β > 1     | **比市場波動大**（如半導體、科技股） |
| β = 1     | 與市場同步                           |
| 0 < β < 1 | **比市場波動小**（如電信、公用事業） |
| β < 0     | 與市場反向（少見，如部分黃金股）     |

### 實務應用

- **多頭預期** → 增加高 Beta 持股放大報酬
- **空頭預期** → 增加低 Beta 持股降低跌幅
- 投資組合的整體 Beta = 各持股 Beta 的加權平均

## 四、績效指標（你的回測工具會輸出）

### 1. Sharpe Ratio（夏普比率）

衡量「**每承受一單位風險可獲得多少超額報酬**」。

$$
Sharpe = \frac{R_p - R_f}{\sigma_p}
$$

| Sharpe    | 評價                                     |
| --------- | ---------------------------------------- |
| < 0       | 比無風險利率還差，**極差**               |
| 0 ~ 1     | 普通                                     |
| **1 ~ 2** | **良好**（多數共同基金的目標）           |
| 2 ~ 3     | 優秀                                     |
| > 3       | 極優（**對個人投資人通常是過擬合警訊**） |

> ⚠️ **Sharpe > 3 的回測結果要警戒**：很可能是**樣本內過度擬合**，實盤難複製。

### 2. Sortino Ratio（索丁諾比率）

只計算「下方波動率」（即虧損時的波動），更符合「投資人怕虧不怕賺」的直覺。

$$
Sortino = \frac{R_p - R_f}{\sigma_{down}}
$$

- **比 Sharpe 更實用**：股價向上劇烈波動不是「風險」
- 解讀區間與 Sharpe 類似但通常數值較高

### 3. Calmar Ratio

$$
Calmar = \frac{\text{年化報酬率}}{|\text{最大回撤}|}
$$

- 考量**最大回撤**（投資人實際感受到的痛）
- > 1 為佳，> 3 優秀

### 4. 最大回撤（Maximum Drawdown, MDD）

$$
MDD = \frac{\text{谷底} - \text{峰頂}}{\text{峰頂}} \times 100\%
$$

- 投資人**心理承受的關鍵指標**
- 一般人能承受 -20%；超過 -30% 多數人會恐慌出場
- 配對「**回本所需漲幅**」表參考：
  - -20% → 需 +25% 才回本
  - -50% → 需 +100% 才回本

### 5. 勝率（Win Rate）

$$
\text{勝率} = \frac{\text{獲利交易數}}{\text{總交易數}}
$$

⚠️ **勝率不是越高越好**。重點是 **勝率 × 平均獲利 vs 敗率 × 平均虧損**：

$$
\text{期望值} = (\text{勝率} \times \text{平均獲利}) - (\text{敗率} \times \text{平均虧損})
$$

- 勝率 30% + 風報比 5:1 = 期望值正
- 勝率 80% + 風報比 1:5 = 期望值負

### 6. 年化報酬率（CAGR）

$$
CAGR = \left(\frac{\text{期末值}}{\text{期初值}}\right)^{1/n} - 1
$$

- 短期績效用「總報酬率」，長期用「年化報酬率」
- 比較不同時間長度的策略時必須年化

## 五、投資組合配置策略

### 60/40 經典配置

- 60% 股票 + 40% 債券
- 美國長期回測年化約 7-9%，最大回撤 -25%
- 適合**穩健型投資人**

### All Weather（全天候）— Ray Dalio

- 30% 股票 / 40% 長債 / 15% 中債 / 7.5% 商品 / 7.5% 黃金
- 應對通膨、通縮、成長、衰退四種情境
- 報酬較低但回撤更小

### 核心衛星策略（Core-Satellite）

- **核心 70-80%**：低成本指數 ETF（如 0050、VT）
- **衛星 20-30%**：個股或主題型 ETF 試圖超越大盤

### 集中 vs 分散

| 持股數   | 類型                 | 適合                 |
| -------- | -------------------- | -------------------- |
| 1-5 檔   | **集中投資**         | 巴菲特派、深度研究者 |
| 5-15 檔  | **適度分散**（推薦） | 多數主動投資人       |
| 15-30 檔 | 高分散               | 接近指數，但難超越   |
| > 30 檔  | **過度分散**         | 不如直接買指數 ETF   |

## 六、配置調整：再平衡（Rebalancing）

長期持有後配置會偏離原始目標，需定期再平衡：

### 方法

- **時間再平衡**：每 6 個月或每年一次
- **閾值再平衡**：當任一資產偏離原配置 ± 5% 時調整

### 效益

- 強迫**高賣低買**（漲多的減碼，跌深的加碼）
- 控制風險不失控
