# 回測結果解讀指南

> 本文配合 `run_strategy_backtest` 工具使用，告訴 Navi 如何解讀回測結果並寫出**誠實、有用**的報告。

## 你的回測工具回傳的指標

`run_strategy_backtest` 會回傳：

| 欄位                   | 意義               |
| ---------------------- | ------------------ |
| `total_return`         | 總報酬率（%）      |
| `annualized_return`    | 年化報酬率（CAGR） |
| `sharpe_ratio`         | 夏普比率           |
| `max_drawdown`         | 最大回撤（%）      |
| `win_rate`             | 勝率               |
| `total_trades`         | 總交易次數         |
| `avg_win` / `avg_loss` | 平均獲利/虧損      |
| `trades`               | 完整交易日誌       |
| `equity_curve`         | 權益曲線           |

策略選項：`ma_cross`、`rsi`、`macd`

## 一、解讀框架（按重要性順序）

### 1. **先看最大回撤（最重要）**

**人能承受的痛是回撤的關鍵指標。**

| 最大回撤        | 評價                               |
| --------------- | ---------------------------------- |
| < -10%          | 優秀，多數人可承受                 |
| -10% ~ -20%     | 良好，較積極投資人可承受           |
| **-20% ~ -30%** | **臨界點**，多數人會在這時恐慌出場 |
| > -30%          | 多數人**會中途放棄策略**           |
| > -50%          | 即使長期年化高，也很難堅持         |

➤ 給用戶看回測時，**先強調最大回撤**而非總報酬，避免他誤以為策略很神。

### 2. 看 Sharpe Ratio

| Sharpe  | 評價                  | 注意                 |
| ------- | --------------------- | -------------------- |
| < 0     | 比定存差              | 這策略沒用           |
| 0-1     | 普通                  | 不值得執行           |
| 1-2     | 良好                  | 大多數共同基金的目標 |
| 2-3     | 優秀                  | 很好的策略           |
| **> 3** | ⚠️ **過擬合警訊**     | 實盤難複製           |
| > 5     | 🚨 **幾乎肯定過擬合** | 不要相信             |

> **個人投資人若回測出 Sharpe > 3，第一反應應是「我有沒有未來函數？」「樣本是否太短？」**

### 3. 看勝率與風報比的搭配

**勝率高不等於策略好**。重點是期望值：

$$
\text{期望值} = \text{勝率} \times \text{平均獲利} - \text{敗率} \times \text{平均虧損}
$$

範例：

| 策略 | 勝率 | 平均獲利 | 平均虧損 | 期望值/筆                  |
| ---- | ---- | -------- | -------- | -------------------------- |
| A    | 80%  | +2%      | -8%      | 0.8×2 − 0.2×8 = **0**      |
| B    | 30%  | +10%     | -2%      | 0.3×10 − 0.7×2 = **+1.6%** |

➤ 策略 B 雖勝率只有 30%，但長期期望值更高（高風報比）

### 4. 看交易次數

| 交易次數 / 年 | 評價                               |
| ------------- | ---------------------------------- |
| < 5           | 過少，樣本不足以判斷策略有效       |
| 5-50          | 合理範圍                           |
| > 100         | 過於頻繁，**手續費磨損會吃掉報酬** |

⚠️ 你的回測**沒有計入手續費和滑價**（多數簡化回測都這樣），實盤要扣除：

- 手續費 0.1425% × 2（買賣各一次）
- 證交稅 0.3%（賣出）
- 滑價 0.1-0.5%（流動性差時更高）

**單筆來回成本約 0.6-1%**，回測獲利每筆 < 1% 的策略**實盤多半賠錢**。

### 5. 看權益曲線形狀

理想：**穩定向上、回撤短淺**  
警戒：**長期橫盤後突然飆升**（運氣好抓到一兩次）  
警戒：**早期驚人成長後逐漸衰退**（策略可能失效）

## 二、過度擬合（Overfitting）警訊

**回測賺錢、實盤賠錢的最常見原因。**

### 常見過擬合警訊

1. **回測期間太短**（< 2 年）
2. **參數最佳化痕跡太重**（明顯的「魔術數字」）
3. **Sharpe > 3** 卻沒有合理的市場學解釋
4. **策略在某個特定時期表現異常好**（如 2020 大跌後）
5. **小樣本下的高勝率**（< 30 筆交易，勝率 80%）

### 如何降低過擬合風險

- **樣本外測試（Out-of-Sample）**：用部分資料訓練、部分資料驗證
- **多市場驗證**：策略在台股有效，在美股、日股是否也有效？
- **未來測試**：實盤模擬 3-6 個月再實際執行
- **避免過度參數化**：MA 5 vs 6 vs 7 變化不大才是穩健策略

## 三、Navi 應該如何寫回測報告

### 推薦格式

```markdown
## 回測結果摘要

**策略**: MA Cross (5/20)
**期間**: 過去 1 年
**起始資金**: 100 萬

### 關鍵指標

| 指標         | 數值       | 評價         |
| ------------ | ---------- | ------------ |
| 總報酬       | +15.2%     | 跑贏大盤 +8% |
| 年化報酬     | +15.2%     | 良好         |
| Sharpe       | 1.32       | 良好         |
| **最大回撤** | **-12.5%** | **可接受**   |
| 勝率         | 45%        | 一般         |
| 交易次數     | 18         | 合理         |

### 解讀

**正面：**

- 策略確實跑贏買進持有約 5%
- 最大回撤 -12.5% 在多數人可承受範圍內

**警示：**

- 樣本期僅 1 年，**樣本不足**，建議延長至 3-5 年驗證
- 勝率 45% 偏低，**心理上需能承受連續虧損**
- ⚠️ **回測未計入手續費**（每筆來回約 -0.6%），實際報酬會比較低
- 18 次交易 × 0.6% = 約 -10.8% 實際磨損

### 適合誰？

- ✅ 有紀律執行訊號的投資人
- ✅ 能承受 -15% 以上回撤者
- ❌ 不適合追求穩定收入者
- ❌ 不適合無法每日盯盤者

### 風險提醒

- 過去績效不代表未來
- 樣本期間市場狀態（如多頭、空頭）可能影響結果
- 建議**先以小資金實盤驗證**，確認可執行後再放大
```

## 四、不同策略的特性

### MA Cross（均線交叉）

- 趨勢追蹤型
- **多頭表現好、盤整表現差**（金叉死叉頻繁）
- 勝率約 30-45%，但風報比通常 > 2
- 適合：**有明顯趨勢的市場**

### RSI（超買超賣）

- 均值回歸型
- **盤整表現好、強趨勢表現差**（鈍化）
- 勝率約 50-60%，但獲利幅度通常較小
- 適合：**區間震盪的市場**

### MACD（動量）

- 趨勢確認型
- 介於 MA 和 RSI 之間
- 滯後性強，適合中線
- 適合：**趨勢確立後跟隨**

## 五、用戶常見誤解（要主動澄清）

| 誤解                                 | 真相                                     |
| ------------------------------------ | ---------------------------------------- |
| 「回測賺 50% = 我也會賺 50%」        | 實盤有手續費、滑價、心理因素，多半打折   |
| 「Sharpe > 2 一定好」                | 要看樣本期、是否過擬合                   |
| 「勝率 80% 神策略」                  | 看風報比，可能單筆虧損吃掉所有獲利       |
| 「回測過去 10 年都賺，未來也會」     | 市場結構變動可能讓過去策略失效           |
| 「最大回撤 -30% 沒關係，反正會回來」 | 心理上**極難承受**，多數人在 -20% 就停損 |

## 六、回測 ≠ 實盤的隱形差距

實際執行時會多出這些成本：

| 項目     | 影響                       |
| -------- | -------------------------- |
| 手續費   | 每筆 -0.28%                |
| 證交稅   | 賣出 -0.3%                 |
| 滑價     | -0.1% ~ -0.5%              |
| 心理偏誤 | 該執行訊號時不執行（恐懼） |
| 流動性   | 大額交易自己推升價格       |

➤ **單筆來回實際成本約 -0.7% ~ -1.5%**

➤ 一個年化 +10% 的回測策略，扣除成本後可能剩 +5%。**不要被回測的漂亮數字騙了。**
