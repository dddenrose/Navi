# 總體經濟對股市的影響

## 概述

股市不在真空中運作，**總體經濟環境**是決定大盤方向的最重要因素之一。本文整理對台股影響最關鍵的總經指標。

> 📌 **核心觀念**：**選股決定報酬上限，總經決定報酬下限**。再好的公司在升息循環、衰退期都難逃下跌。

---

## 一、利率（最重要）

### 為什麼利率影響股市？

1. **折現率變高 → 股票估值下降**（DCF 折現率上升）
2. **企業借貸成本上升 → 獲利下滑**
3. **無風險利率上升 → 資金從股市流向債市**

### Fed 利率（影響全球）

- 台股**雖在台灣**，但與美股、美元連動極深
- Fed **升息循環** → 全球資金回流美國 → 新興市場（含台股）承壓
- Fed **降息循環** → 資金外流找報酬 → 新興市場受惠

### Fed 政策週期

| 階段           | 利率         | 股市傾向                       |
| -------------- | ------------ | ------------------------------ |
| **升息初期**   | 由低升高     | 通常還在多頭，市場逐步消化     |
| **升息末段**   | 利率高點附近 | **多空轉折**，警戒衰退         |
| **首次降息**   | 開始下降     | **常伴隨股市下跌**（衰退來臨） |
| **降息中後段** | 持續下降     | 股市開始反彈，預期經濟復甦     |
| **零利率**     | 極寬鬆       | 流動性過剩，股市上漲           |

### 台灣央行（CBC）

- 一年 4 次理監事會議（3、6、9、12 月）
- 通常**跟隨 Fed 但幅度較小**
- 影響台幣定存利率、房貸利率，間接影響股市資金面

### 殖利率曲線倒掛（Inversion）

- **短期公債殖利率 > 長期公債殖利率**
- 美國歷史上，**倒掛後 12-24 個月內常有衰退**
- 台股反應通常落後美股 3-6 個月

---

## 二、通膨（CPI / PPI）

### CPI（消費者物價指數）

- Fed 利率政策的主要參考
- **目標通膨**：美國 2%、台灣 2%
- CPI 高 → Fed 升息 → 股市承壓
- CPI 急降 → Fed 降息 → 股市受惠

### PPI（生產者物價指數）

- **領先 CPI 1-3 個月**
- PPI 上升 → 企業成本壓力 → 利潤可能被壓縮
- PPI 下降 → 成本減壓 → 毛利率回升空間

### 通膨對不同產業

| 通膨環境 | 受惠                 | 受害                   |
| -------- | -------------------- | ---------------------- |
| 高通膨   | 原物料、能源、REITs  | 科技、消費（成本壓力） |
| 通縮     | 防禦類（民生、電信） | 金融（利差縮小）       |

---

## 三、PMI（採購經理人指數）

### 解讀

- PMI > 50：**製造業擴張**
- PMI < 50：**製造業萎縮**
- 台灣 PMI 由 IHS Markit 與 中華採購協會 發布
- **領先指標**：常領先 GDP 1-3 個月

### 對台股影響

- 台灣是出口導向經濟，**PMI 與電子股高度相關**
- **美國 ISM 製造業 PMI** > 台灣 PMI 影響更大
- PMI 連續 3 個月低於 50 → 衰退警訊

---

## 四、匯率（台幣 / 美元）

### 對台股的影響

| 匯率變動                    | 受惠                         | 受害               |
| --------------------------- | ---------------------------- | ------------------ |
| **新台幣貶值**（USD/TWD ↑） | 出口商（台積電、鴻海、廣達） | 進口商、航空、塑化 |
| **新台幣升值**（USD/TWD ↓） | 進口商、內需股（台塑、統一） | 出口商             |

### 美元指數（DXY）

- 美元強勢期 → 全球資金回流美國 → 新興市場（含台股）承壓
- 美元弱勢期 → 資金外流 → 新興市場、商品上漲

### 重要關卡（USD/TWD）

- **30** 以下：台幣強勢
- **30-32**：常態區間
- **32 以上**：台幣弱勢，出口商受惠

---

## 五、債券殖利率

### 美國 10 年期公債殖利率

- **股市的「重力」**——10Y 越高，股票相對吸引力越低
- 高估值科技股對 10Y 最敏感（折現率影響大）
- 台積電 ADR 與 10Y 呈一定的負相關

### 殖利率曲線

- 正常：長天期 > 短天期
- 倒掛：短天期 > 長天期 → **衰退預警**
- 陡峭化：長短天期差距擴大 → 經濟復甦預期

---

## 六、台股獨有的影響因素

### 美國半導體景氣

台股約 60% 市值在半導體相關，**美國費城半導體指數（SOX）對台股影響極大**。

- SOX 上漲 → 台積電、聯發科、ASE 等跟漲
- 重要訊號：NVIDIA、AMD、INTC 法說

### 中美關係

- 科技戰、晶片管制 → 半導體類股波動
- 台海緊張 → 外資撤離壓力（但通常短暫）

### 美國對台軍售、台灣國防預算

影響軍工股、特定電子供應鏈。

### 中國經濟

- 中國經濟強 → 台塑、台水泥、貨櫃航運等受惠
- 中國放緩 → 連動觀光、傳產出口

---

## 總經對股市影響的時序

### 領先指標（領先 3-12 個月）

- 殖利率曲線、PMI、消費者信心、新訂單

### 同步指標

- GDP、企業獲利、就業率

### 落後指標（落後 3-6 個月）

- 失業率、CPI、利率政策（Fed 通常落後實體經濟）

---

## 投資人應對策略

### 升息週期

- 減碼**長存續期**資產（成長股、長債）
- 增加**金融股**（利差擴大受惠）
- 留更多**現金**等下車機會

### 降息週期

- 增加**成長股**（折現率下降受惠）
- 增加**長債 ETF**（殖利率下降帶動價格上漲）
- 減少現金部位

### 衰退預警時

- 減碼**景氣循環股**（航運、鋼鐵、原物料）
- 增加**防禦股**（電信、民生、健保）
- 增加**美國公債、黃金**

### 通膨高漲時

- 增加**原物料、能源**
- 減少**長存續期債券**
- 適度增加**抗通膨資產**（REITs、TIPS）

---

## Agent 解讀提示

當用戶問「現在該不該進場」「未來幾個月怎麼看」時，可以參考：

1. **Fed 在哪個階段？**（升息初/末、降息中）
2. **殖利率曲線正常還是倒掛？**
3. **CPI 趨勢向上還向下？**
4. **PMI 在 50 以上還以下？**
5. **美股、SOX 趨勢？**

➤ 不要單看技術分析或個股，**總經背景是大方向**。
